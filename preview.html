Tools

GenoMiss

Python tool to detect potential gene misannotations by fusing adjacent genes and comparing their alignment scores against reference protein databases.

github.com/txdylan27/GenoMiss

GenoFrag

Python tool to synthetically fragment genes in .gff and .faa files.

github.com/dr-dvice/GenoFrag
